# 宠物眼中的你 · PET'S EYES

上传一张宠物的照片，AI 用它的眼睛说出"在它眼里你是个什么样的人"，并生成一张 3:4 的分享卡。

## 二、日常怎么运营

### 1. 放收款码（上线前必须做）

把你的微信/支付宝收款码存成 `assets/pay.png` 传进仓库。没有这个文件时，付费弹窗会显示"收款码还没放进来"，不会崩，但用户付不了钱。

### 2. 发兑换码

`codes.txt` 里有 200 个码，格式 `XXXX-XXXX`。**这个文件不要传到 GitHub。**

流程：用户付费 → 把截图发到小红书私信 → 你从 codes.txt 里取一个没发过的码回他 → 他在页面输入 → 解锁。

前端存的是**哈希**（config.js 里的 `unlockHashes`），所以别人扒走 config 也读不出码。

码不够了：跑 `node tools/make-codes.mjs 100`，把打印出来的哈希追加到 `unlockHashes`，新码记到 codes.txt。

### 3. 额度怎么调

- **单设备每天的次数**：`config.js` 的 `dailyLimit`，默认 30。同一张图命中缓存不计数。
- **模型账号的额度**：阿里云百炼控制台 → 费用与成本 / 额度管理，`qwen3-vl-plus` 按 token 计费。一次调用约 4000 tokens（图 2300），成本几分钱到一毛。
- **被蹭 Key 的止损**：给这个站点单独开一个业务空间，只充少量额度（比如 50 元），被刷光也只是 50 元。控制台里换 Key 后，只改 `config.js` 的 `apiKey` 一行。

### 4. 自己测（不花钱）

打开 `?admin=1` 一次，这台设备就永久免付费墙（存在 localStorage）。测完记得清掉：控制台执行 `localStorage.removeItem('pe_admin')`。

### 5. 本地预览

```
python3 -m http.server 8765
# http://127.0.0.1:8765/?dev=1&auto=1&demo=1
```

- `dev=1` 自动载入 `assets/sample-cat.jpg`
- `auto=1` 自动点"让它看看我"
- `demo=1` 用内置样例，不打模型（省钱、快）
- `qa=1` 关动画，方便截图
- `card=1` 自动弹分享卡

## 三、收款怎么接（三档，按现状选）

### 阶段一：兑换码（现在就能用，零成本）

页面收 0.98 → 用户扫码付款 → 私信截图 → 你回码。缺点是要人工，但量小的时候反而赚了私域。

### 阶段二：自动发码（要一个能跑回调的服务）

接虎皮椒 / PayJS 这类个人可注册的支付网关，付款成功回调后由服务端自动发码。需要一个已备案域名 + 一台小服务器（阿里云 FC 或轻量应用服务器）。改 `app.js` 里 `verifyCode()` 换成请求接口即可。

### 阶段三：微信支付商户号（规模化）

注册个体工商户 → 申请微信支付 → H5/JSAPI 支付，费率 0.6%，真正自动化。注意：**微信小程序 iOS 端禁止虚拟支付**，网页 H5 反而没这个限制。

## 四、防盗的三层

1. **域名锁**：`config.js` 的 `allowedHosts`。别人把文件整站抄走换个域名，页面直接显示"这一页只对授权域名开放"。
2. **隐形水印**：每张分享卡里用 2.6% 透明度的白字写了 `PETSEYE·<图片指纹>·<域名>`，肉眼看不见，但能证明是你的卡流出去的。
3. **兑换码哈希**：线上只有哈希，没有明文。

**做不到的部分**：纯静态站没法真正藏住 API Key。要彻底防白嫖，必须把 Key 挪到服务端（见阶段二）。现在用"小额度业务空间"把损失封顶。

## 五、小红书怎么发

- **主图用小红书版**（不带二维码）。小红书对图里的二维码/微信号识别很严，容易被限流。
- **朋友圈/私信用带码版**，扫了直接进站。
- 标题模板：`我家猫眼里的我居然是这样` / `测完有点想哭，它一直在看我` / `它说我像人形暖炉`
- 文案里不放"预测、运势、命"，只写"它觉得""它看见"。
- 评论区自己留一条：`入口在主页简介`，别在正文放链接。
- 结果页底部已写明"AI 生成内容，仅供娱乐"，这是合规要求。

## 六、技术说明

- 纯静态：`index.html` / `style.css` / `app.js` / `config.js`，无构建步骤。
- 二维码：`vendor/qrcode.js`（MIT，本地文件，不依赖 CDN）。
- 模型：阿里云百炼 `qwen3-vl-plus`，OpenAI 兼容接口，浏览器直连（已确认支持 CORS）。
- 图片：上传后浏览器内压到 1280px JPEG 0.82，只在内存里处理，不落盘不上传。
- 缓存：`localStorage` 存最近 5 份结果（含 420px 缩略图），同一图片指纹直接复用。
- 指纹：压缩后 dataURL 的 djb2 变体，同一张图稳定同值。

## v3 变更（2026-11-26）

### 1. 模型换成免费的
`config.js` 顶部 `provider: "zhipu"`，`apiKey` 填智谱的 Key（`open.bigmodel.cn` → API Keys）。
用的是 `glm-4.6v-flash`，**输入输出全部免费**，128K 上下文。一次测试模型成本 = 0 元。
想更准可以换成 `glm-4.6v`（1 元/百万输入 tokens，一次约 0.004 元）。
百炼（qwen3-vl-plus）保留在 `providers.dashscope`，改 `provider` 就能切回去，但那是按量付费的。

因为模型免费，"Key 写在前端被扒走"这件事的损失从"烧钱"变成"别人用你的额度"，几乎可以忽略。

### 2. 收费模式：先出结果，再打码收钱
`payMode: "after"`（默认）：
上传 → 跑模型（免费）→ 结果页露出人格名、照片、三个分数、verdict → 正文（情话/五件事/对比/偷偷做的事/吐槽/愿望）**打码** →
页面弹出"￥0.98 解锁完整版" → 扫码付 → 输码 → 原地去码，**不会重新调用模型、不会二次收费**。
`payMode: "before"` 是旧逻辑（先给三个取景读数，付费后才跑）。

结果在生成时就存进 localStorage，所以「付钱时手机不在手上」也没关系：回来点首页"上次的记录"，输码即可看全文。

### 3. 一键保存
结果页最下面第一个按钮是「一键保存这张卡」：
- iOS/安卓新浏览器 → 走系统分享面板（可直接存相册、发微信、发小红书）
- 微信内置浏览器等不支持分享的环境 → 自动把卡片转成图片显示，长按即可存相册

### 4. 分享卡标签
选项卡只写「朋友圈版 / 小红书版」，不再出现"带二维码""防限流"这类字眼。
朋友圈版带二维码，小红书版不带码（小红书对图内二维码识别严，容易限流）。

### 5. 自动发码（可选）
`autoCodeUrl` 填发卡平台（面包多 / 爱发电 / 易支付）的商品页链接，付费抽屉第二步会多一个"自助拿码 →"。
这样用户半夜付款也能自己拿到码，不用等你在线。没填就保持人工发码。
