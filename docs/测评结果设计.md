# 「宠物眼中的你」测评结果设计

> 一句话定位：**通过宠物，看见你自己。**
> 宠物是唯一一个"无条件爱你的观察者"。同样一句夸奖，从人嘴里说出来是客套，从它嘴里说出来就是"证据"。

## 一、为什么这个产品成立

宠物照片里其实藏着"人"。人不在画面里，但通过四件事，人的形象被勾出来了：

- 它**看向哪里**（看向镜头外，就是看向你）
- 它**待在哪里**（你的床、你的工位、你腿上的那块布）
- 它**是什么状态**（毛发、体态、眼神亮度、有没有戴东西 = 你有多上心）
- 它**身后的房间**（秩序、光线、有没有专属于它的角落 = 你的生活长什么样）

这就是整个产品的物理基础：**输入是一张宠物照，输出是关于你的解读。**

三层结果结构：

| 层 | 内容 | 用户心理 |
|---|---|---|
| 第一层 | 它怎么看你（**一个命名**） | "我被读懂了" |
| 第二层 | 它凭什么这么看（**画面证据**） | "这不是套话" |
| 第三层 | 它想对你说的话（**一句金句**） | "我要存下来" |

分享的驱动力不是炫宠物多可爱，而是**炫"我和它之间有故事"**。宠物的口吻还天然免疫"AI 评价人"的冒犯感——评价者是它，被评价者是你，全程软的。

## 二、可分析线索池（喂给模型的观察清单）

**A. 宠物本体**：眼神朝向、瞳孔与耳朵状态、身体松紧度、嘴部（微张/舔鼻/闭紧）、尾巴姿态、毛发光泽与整洁度、体态胖瘦、配饰（项圈/衣服/名牌/蝴蝶结）。

**B. 人与它的接触痕迹**：画面里有没有手/腿/膝盖、腿上有没有被压出的印、宠物朝向镜头的角度（是否在看拍照的人）、被摸过的毛发走向、是否靠在你身上。

**C. 环境**：背景秩序度、地面材质、有没有玩具堆/猫爬架/狗窝、家具相对高度、有没有专门为它摆的垫子、光线来源与色温、是否有"人为了它改造过"的痕迹。

**D. 影像语言**：视角（俯拍/平视/贴地）、距离、是否摆拍、构图是否刻意——读出"你有多想把它拍好看"。

## 三、五维解读体系

每个维度固定输出三段：**一句判断 → 一条画面证据 → 一条你没意识到的事**。

1. **眼神**（它在用什么方式看你）：依赖 / 平等 / 审视 / 宠溺 / 求关注
2. **距离**（它选的位置离你多远）：贴身 / 守着 / 隔着 / 各自独立
3. **照料**（它的状态暴露你的性格）：精致 / 松弛 / 放养 / 过度紧张
4. **家的秩序**（背景读你的生活）：克制 / 丰盛 / 临时感 / 有收藏癖
5. **角色**（你在它心里是谁）：父母 / 室友 / 玩伴 / 安全基地 / 饭票

## 四、三个可比较指数（0–100）

**信任度 / 依赖度 / 默契值**

选这三个的理由：它们不评价宠物好坏，只描述关系；安全、可晒、天然可对比（"我和我家猫默契 43 分，笑死"），是低风险的社交货币。

## 七、结果页结构（从上到下）

1. 首屏大卡：人格名（大字）+ 副标题 + 宠物照片
2. 三个指数条（进度动画，依次点亮）
3. 五维解读（可展开，每维一句话 + 证据 + 洞察）
4. 反差洞察："你以为的 vs 它眼里的"双栏对照
5. 它想对你说的一句话（大字排版，留白，分享核心）
6. 三条"它偷偷希望的事"
7. 保存卡片 / 复制文案 / 再测一只

## 八、分享卡（3:4 竖版，1080×1440）

- 顶部：人格名（大）+ 副标题
- 中部：宠物照片（拍立得白边）
- 下部：三指数 + 一句金句
- 底部：小字"宠物眼中的你 · 测你家那只"
- 规则：字少、留白多、金句 <30 字、一眼可读、不看正文也能懂

## 九、文案与语气规则（护栏）

- **主语永远是"它"，不是"你"**：所有评价由宠物说出，人是被观察的一方 → 天然去冒犯。
- **只夸具体**：每条判断必须挂一条画面证据，禁止"你很温柔"这类无证据的套话。
- **不评价宠物外貌**：不说胖/瘦/丑，只说状态（"它最近很放松"）。
- **不做医疗与训练建议**：把"它该减肥"换成"它想让你陪它多跑两圈"。
- **可以调侃人，绝不调侃宠物**。
- **不确定性必须软化**：用"看起来""也许""我猜"，绝不断言。照片信息不足时，以环境线索为主，不硬编细节。

## 十、技术方案

- 前端：纯静态单页（HTML + CSS + JS），部署 GitHub Pages，无需后端
- 模型：**阿里云百炼 qwen3-vl-plus**（OpenAI 兼容接口，中文与图像理解强）；实测 `qwen-vl-max-latest` 在测试账号下返回 403、`qwen-vl-plus` 返回 404，故选 `qwen3-vl-plus`。备选 智谱 GLM-4.5V
- 调用方式：浏览器把图片压到 1280px 后转 base64，POST `/chat/completions`，`temperature 0.7`
- 兜底：未配置 Key 时进入"演示模式"，用本地规则生成一份完整结果，保证页面永远可演示
- 隐私：图片仅在浏览器内压缩后直传模型，不落任何服务器；页面明确写这句

## 十一、风险与对策

| 风险 | 对策 |
|---|---|
| 用户上传的不是自己的宠物 | 文案不依赖身份，只描述关系，无影响 |
| 照片太糊/太远，线索不足 | 降低维度颗粒度，转向环境解读，不硬编 |
| 模型输出格式跑偏 | 前端做 JSON 容错解析 + 缺字段回填 |
| 过度解读让人不适 | 全部判断加软化词，禁止断言人生 |
| 用户觉得"被 AI 评判" | 视角永远放在宠物一侧，人只是被看见 |
